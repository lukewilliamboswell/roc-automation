= Roc package starter

Copy this directory, including `.github/`, to a package repository root. Keep
`Blueprint.roc` and `Blueprint.lock` together and review the lock when changing
recipes. The manual owns the
https://lukewilliamboswell.github.io/roc-automation/pure-package.html[setup and local commands]
and the https://lukewilliamboswell.github.io/roc-automation/workflows.html#the-shared-release-workflow-for-a-pure-package[shared release caller].

This starter also exercises the release utility in CI: a file example, a directory
example with a sibling module, and a second package bundle. Recorded expectations,
notes and the archived files are checked through the same shared utility consumers use.
