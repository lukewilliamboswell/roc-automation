# roc-automation tools 0.11.0

The release utility admits portable harnesses and fixture assets beneath the exact versioned examples archive root. Required README/specification files, release identity, declared application membership, dependency equality and application headers remain checked before execution. Native regressions run a declared archived harness that consumes benchmark fixtures and aliased assets.

`RP_CASE_TIMEOUT_MS` configures the deadline for each case run by `test-examples` and `test-archive`. It accepts 1–120000 milliseconds and defaults to 10000. Compiler checks and builds retain their separate five-minute deadlines. Tests cover admission bounds, propagation through both commands and interruption of a running case.
