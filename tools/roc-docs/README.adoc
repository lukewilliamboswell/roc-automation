= roc-docs

Build a documentation website, static Markdown and searchable PDF from AsciiDoc
or Markdown with one released executable, including native Mermaid diagrams.

[source,sh]
----
roc-docs build --workspace . --pdf-filename project.pdf --docs-version 1.2
----

The website is `.docs-out/site/`; the PDF is also `.docs-out/project.pdf`.

* link:https://lukewilliamboswell.github.io/roc-automation/roc-docs.html[Utility reference]: commands, supported sources, images and diagrams.
* link:https://lukewilliamboswell.github.io/roc-automation/documentation.html[Authoring guide]: write and publish one coherent manual.
* link:https://lukewilliamboswell.github.io/roc-automation/maintain-roc-docs.html[Renderer maintenance]: build, test, architecture and fonts.
* link:https://github.com/lukewilliamboswell/roc-automation/releases[Releases]: executables for Linux x86-64, Linux ARM64 and Apple Silicon.

The reference and maintenance sources live in
link:../../docs/roc-docs.adoc[docs/roc-docs.adoc] and
link:../../docs/maintain-roc-docs.adoc[docs/maintain-roc-docs.adoc].
