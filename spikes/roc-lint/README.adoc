= Archived Roc policy spike

The feasibility implementation has been promoted to `tools/roc-policy/`.
See `tools/roc-policy/README.adoc` for development commands and
`docs/policy.adoc` for the implemented configuration and runtime contracts.

`ideal-design.adoc` retains the initial design exploration. It includes proposed
profiles, evaluated Blueprint agreement and bootstrap installation that are not
implemented in this change. The production reference takes precedence over
these historical proposals. The generic constant-data resolver is maintained
separately for a possible future roc-parser upstream proposal.
